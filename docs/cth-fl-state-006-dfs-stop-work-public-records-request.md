# Draft — Florida DFS Stop-Work Public-Records Request

**Status: DRAFT ONLY — NOT SENT**

To: Florida Department of Financial Services, Division of Workers’ Compensation / Public Records

Please provide, if publicly releasable, a machine-readable export (CSV preferred) of workers’ compensation stop-work and related compliance-enforcement records from January 1, 2004 through the current extract date.

Requested fields, where maintained:

- stable stop-work order identifier;
- case or enforcement identifier;
- DFS employer identifier and FEIN;
- employer legal name and official business/location address;
- date served, date ended, and date reinstated;
- exact noncompliance reason and maintained order status;
- proposed, assessed/final, paid, and outstanding penalty amounts as distinct fields;
- payment-plan indicator and settlement/reduction fields, if distinct;
- DOAH case number, final-order number, appeal/hearing status;
- stable order/document URL or document identifier;
- created and updated timestamps;
- field dictionary, status/amount semantics, historical-retention behavior, and update cadence.

Please identify whether multiple indistinguishable displayed rows can represent separate orders and provide the authoritative key that distinguishes them.

Please exclude Social Security numbers, employee/claimant information, personal financial information, and unnecessary personal contact information. Business identity and business-location fields are requested only where public and necessary to identify the regulated employer.

Preferred delivery is a complete versioned extract with an extraction timestamp and checksum, plus documentation describing corrections, deletions, and historical status changes.
