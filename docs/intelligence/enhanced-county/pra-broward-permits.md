## Scope

Existing electronic building-permit records held by **Broward County Building Code Division** for the jurisdictions **actually maintained by the County system** (BMSD / unincorporated Broward, county-issued permits for contract cities, associated county approvals if stored in the same system, elevator records if stored in the same system).

This is **not** a request for all Broward **municipal** building permits issued by city building departments (Fort Lauderdale, Hollywood, Pembroke Pines, etc.) unless those rows are **actually county-issued** and held in this system.

Please label each file/row with the jurisdiction/AHJ as stored.

**Time range:** 2023-01-01 through current, **plus** all currently open/unfinaled permits regardless of original issue date, where existing export capability permits. If a five-year native extract is equally practical, that broader period is acceptable.

**Do not include:** plans, drawings, architectural/engineering sealed documents, or other heavy attachments.

**Do not include:** Social Security numbers, dates of birth, driver’s license numbers, bank/payment data, payment cards, or private account credentials. Lawful redaction of exempt fields is accepted.
