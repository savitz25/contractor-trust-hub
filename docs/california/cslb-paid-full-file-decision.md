# CSLB paid Full File decision (CA-CON-002)

**Decision: DO_NOT_BUY_FOR_CA_CON_002**

Price: **$235** REQUEST_ONLY.

CSLB describes the paid Full/Update file as roughly **700,000–830,000+** historical records, including current, expired, cancelled, and revoked licenses. That file is not required to publish an honest California research page.

## Why not now

1. Official CSLB identity is proven from the free Public Data Portal License Master.
2. The accepted extract is deterministic: **75,572** license rows, SHA-256 `f6ebbee6ed6c8b9476414e972382e6fcb4065f2c6e88a19392371a1e1e996838`, as of 2026-09-02.
3. The free portal already excludes cancelled/revoked/expired-nonrenewable rows. Buying the Full File would add a *historical* universe, not finish the truncated renewable stream.
4. Historical paid Full File absence is **not a page blocker**.
5. No revocation/cancellation research product is authorized in this ticket.

## When to reconsider

Buy later only if a separately authorized product needs cancelled/revoked/expired-nonrenewable history, legal-action disclosure, or a true complete-universe denominator that the free portal will never provide.

Do not purchase in order to paper over a flaky bulk download. Document the gap and move forward.

No purchase was made in CA-CON-002.
