# NJ-CON-001 OPRA request (PWCR roster and prevailing-wage debarment)

Official NJDOL pages publish both lists only as Power BI interactive views. There is no supported public CSV/XLSX/JSON full-file export. This ticket does not reverse-engineer or bypass Power BI authentication.

Use this narrowly scoped request. Do not ask for certified payroll, permits, or DCA HIC files.

## Proposed language

Please provide, in a machine-readable delimited file (CSV, TSV, or Excel) covering the current official lists maintained by the Division of Wage and Hour Compliance:

1. **Public Works Contractor Registration (PWCR) current roster**, including for each registrant, where maintained:
   - Legal / business name
   - PWCR certificate / registration number
   - Registration status as published
   - Registration effective date
   - Registration expiration date
   - Business address, city, state, ZIP
   - Any public owner/officer name that already appears on the public list
   - Source as-of / publication date

2. **Prevailing Wage Act debarment list (current)**, including for each firm or individual, where maintained:
   - Firm name
   - Individual name (when the list is person-grained)
   - Address fields as published
   - Debarment / ineligibility action
   - Official reason or statutory citation as published
   - Debarment start date
   - Debarment end date
   - Source as-of / publication date

Please do not substitute a screenshot or Power BI embed for the file. Historical vintages are useful if already compiled, but the current lists are the minimum needed to match the public interactive views.

Requester purpose: independent public-records research to store official source observations. The records will not be collapsed into a consumer “score” or “vetted contractor” badge.
